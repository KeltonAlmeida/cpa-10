CPA-10 Studio - Deploy estático na Vercel

Este projeto é HTML, CSS e JavaScript puro. Não precisa de Node, React, Vite, build ou dependências.

DEPLOY:
1. Extraia o arquivo ZIP.
2. Na Vercel, crie um novo projeto e importe este diretório/repositório, ou use Deploy Project.
3. Deixe Framework Preset como Other.
4. Deixe Build Command e Output Directory vazios (ou sem build).
5. O arquivo index.html deve ficar na raiz do projeto.

Se usar GitHub: envie index.html, vercel.json e este README para a raiz do repositório e importe o repositório na Vercel.
